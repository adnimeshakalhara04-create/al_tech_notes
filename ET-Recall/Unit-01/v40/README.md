# ET Unit 01 v40

Build: `v40-original-inline-images`

- Uses the exact original Unit 01 Google Drive image for every mapped image question.
- Practice, All Questions, and Memory use the real visible image elements (`.qimg` and `.thumb`).
- Images render inline with the question using `contain`; there is no touch-to-zoom image viewer.
- Tapping/clicking an image does nothing and does not flip the Practice card.
- The old compressed atlas is used only as a last-resort per-image fallback if a private Drive image cannot load.
- Keeps the 300-question app, PWA installation, fullscreen support, ET Unit 01 name and icon.

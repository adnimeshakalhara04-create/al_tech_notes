# ET Recall — Unit 01 Premium Quiz

A/L Engineering Technology — Grade 12, Unit 01: **ඉංජිනේරු තාක්ෂණවේදය හැඳින්වීම**.

## Learning model
- **බැරි** basket — cards that still need practice.
- **පුළුවන්** basket — cards the learner has mastered.
- Tap a basket → see a question → flip the card for the answer → self-classify the card.
- Section filters: 1.1–1.5.
- Random practice and progress tracking.
- Orange + black premium responsive UI.
- Question set is based on the Unit 01 lesson content supplied in the ET Lessons Discussion project.
- User-supplied lesson images are used as visual recall cards in the full build.
